# 设计说明

## 1. 产品定位

`mm-ai-music-refiner` 是厂商无关的 AI 音乐质量诊断与非破坏优化项目。输入可以来自 Suno、Udio、Lyria、ACE-Step、Mureka、DAW 或普通录音链；输出描述制作质量与处理历史，不判定作品由真人还是 AI 创作。

创作前的歌词、Style 和 Suno 标签任务属于独立项目 `mm-suno-creator`。两个项目可以串联，但职责、依赖和发布周期独立。

## 2. 用户目标

- 快速了解音频格式、响度、峰值、速度、调性和定音状态；
- 把问题定位到文件或时间范围，并看到算法证据与置信度；
- 以保守、均衡、深度或仅 DAW 方案处理问题；
- 在未来工作台中接受、拒绝、调强度和进行响度匹配 A/B；
- 从 Edit Manifest 确定性重建导出结果；
- 保留原始文件、来源凭证和完整修改记录。

## 3. 总体架构

```text
Codex Skill（任务理解、模式选择、解释与审核门）
        ↓
本地 CLI / 后续 FastAPI
        ↓
音频分析核心 ──→ Issue 规则与优先级
        ↓                 ↓
后续修复核心       Report / Project / Edit Manifest
        ↓                 ↓
后续 React + Tauri 多轨工作台
```

当前仓库的 `v0.1.0` 已实现粗体链路中的 CLI、快速分析、Issue、Project 和报告；修复核心与工作台只保留接口和 Schema，不伪装成可用功能。

## 4. 当前处理流程

```text
输入文件
  ↓
ffprobe：容器 / 编码 / 采样率 / 声道 / 时长
  ↓
SHA-256 与可选只读快照
  ↓
FFmpeg EBU R128：Integrated LUFS / LRA / True Peak
  ↓
受控临时 PCM 代理：Peak / RMS / Crest / DC / Clipping
  ↓
快速音乐估算：BPM / Key / Tuning + Confidence
  ↓
Issue 规则：Severity / Confidence / Audibility / Risk / Actions
  ↓
project.json + analysis.json + issues.json + Markdown/HTML
```

代理文件在受控临时目录中生成并自动清理。报告不记录完整私人路径；源文件只读，只有用户提供 `--snapshot` 时才复制到项目目录。

## 5. 数据模型

### Project

保存项目 ID、输入文件名和哈希、模式、引擎版本、快照相对路径以及来源凭证状态。聊天记录不是项目事实源。

### Metric

记录规范 ID、数值、单位、适用条件和置信度。Key、Tuning 和音域必须分开；外部 MD/MP 等缩写只有在来源和公式确认后才能映射。

### Issue

每个问题包含指标、分类、范围、音轨、严重度、置信度、可听性、证据、可能原因、修复风险、建议动作和状态。

### Edit Manifest

后续每项修改保存关联 Issue、模块、时间范围、参数、风险等级、批准者、前后指标和引擎版本。最终音频必须能从原件与 Manifest 重渲染。

## 6. 修复风险设计

| 等级 | 含义 | 默认行为 |
|---|---|---|
| A | 高置信、低副作用 | 可自动执行并记录 |
| B | 通常有益但影响听感 | 生成响度匹配 A/B，可撤销 |
| C | 可能改变演唱或风格 | 修改前必须确认 |
| D | 无法从最终混音可靠修复 | 只给人工、重唱或重生成方案 |

系统不会因为发现异常立即修改。它先判断可听性、目标相关性、分轨质量、更低风险方案、局部处理能力、可验证指标和新伪影风险。

## 7. 安全与来源边界

- 不把频谱、重复、人声伪影或有损编码当作 AI 来源证据；
- 不针对第三方检测器反向优化；
- 不用随机加噪、随机抖动或移调制造“真人感”；
- 不攻击或移除未知水印；
- 不复制失效凭证并声称仍然有效；
- 未检测到公开凭证时只报告“未知”。

## 8. 技术取舍

`v0.1.0` 只依赖 Python 标准库和用户系统的 FFmpeg，优先验证数据、Schema、报告和测试链路。分轨、歌声分析与高级 MIR 模型会显著增加模型权利、许可证、内存和回归风险，因此必须以可替换后端逐步加入。

## 9. 版本路线

- `v0.1.x`：稳定快速体检、Schema、报告和黄金音频容差；
- `v0.2.x`：时间码异常、Click/Peak 保守修复、局部 A/B、Edit Manifest 闭环；
- `v0.3.x`：可选 4-stem、更多稳定指标和本地 API；
- `v0.4.x`：React/Tauri 多轨工作台；
- `v0.5.x`：人声、旋律、结构高级分析与有界修复；
- `v1.0.0`：跨平台生产发布、迁移、完整回归和许可证台账。

路线不代表未发布能力已经可用；实际交付以 [CHANGELOG](../CHANGELOG.md) 为准。
