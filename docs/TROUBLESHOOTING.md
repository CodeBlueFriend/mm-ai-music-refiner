# 故障排除

- 无法读取：先运行 `ffprobe INPUT`，确认文件不是损坏或 DRM 封装。
- 缺少 FFmpeg：把 `ffmpeg` 和 `ffprobe` 加入 PATH，二者版本应匹配。
- BPM/Key 误判：快速估算对自由速度、弱瞬态、单音和转调材料有限；保留置信度并人工核听。
- LUFS 不可用：极短或全静音文件可能返回空值。
- 输出目录非空：换一个新目录；工具刻意拒绝覆盖已有工程。
- 项目过大：只有使用 `--snapshot` 才复制源文件；不需要快照时可省略。
- Content Credentials：v0.1 不验证，状态会如实显示 `not_checked`。
- 生成诊断包但不上传：当前 CLI 无网络代码，直接在离线环境运行即可。
